# Helene's Candy Quest

A free, family-friendly quest and a new entry beside [Helene's Treasure Chest](https://ploug76.github.io/helenes-treasure-chest/) and [Volume 2](https://ploug76.github.io/helenes-treasure-chest-vol-2/). Those games are not changed.

Helene walks six original candy lands, collecting sweets and hopping kindly obstacles, until the candy crown is home in her chest.

## Play
Open `index.html` from this folder (a local web server is best). Portrait and landscape both work.

## Controls
- **Touch:** hold ◀ ▶ to walk, tap **JUMP**. Swipe up on the land to jump too.
- **Keyboard:** arrows or A / D to walk, Space, W, or Up to jump, P to pause, M for sound.
- **Controller:** stick or D-pad walks, A jumps, Start pauses, B goes back. Menus use the D-pad.

## Saves and scores
Progress, stars, and best scores stay on the device (`hcq_save_v1`). A finished quest can post to the shared arcade leaderboard (`helenes-candy-quest__quest`), the same Firestore board the other Helene games use.

This folder is not linked from the arcade homepage yet.
